# Proyectos Java - NetBeans

Repositorio que contiene los proyectos desarrollados en **Java / Java Swing (NetBeans IDE)**:

## Proyectos Incluidos

1. **Empleados (`empleados` / `proyectos_subidos/empleados`)**:
   - Sistema de Registro de Empleados en Java Swing (`JFrame`, `JTable`, `JSpinner`, `JComboBox`, `JFormattedTextField`) con validaciones de Nivel Básico, Intermedio y Avanzado (estadísticas de cantidad, promedio salarial y mayor salario).
   - Ver [Documentación Técnica](DOCUMENTACION.md).
2. **Alumnos (`proyectos_subidos/alumnos.java`)**:
   - Registro y formulario de alumnos en Java Swing.
3. **Método (`proyectos_subidos/metodo`)**:
   - Proyecto de clases y métodos (`persona`, `principal`).
4. **Proyecto Café (`proyectos_subidos/projec_cafe`)**:
   - Gestión de cafetera en Java (`cafetera`, `Projec_cafe`).
5. **Proyecto Formulario (`proyectos_subidos/projec_formulario`)**:
   - Formularios gráficos en Java Swing (`principal`, `Auxiliar`).
6. **Restaurante (`proyectos_subidos/Restaurante`)**:
   - Sistema de restaurante y comidas (`Restaurante`, `Comidas`).
7. **Veterinaria (`proyectos_subidos/veterinaria`)**:
   - Gestión de mascotas y veterinaria (`Mascota`, `Veterinaria`, `Principal`).
